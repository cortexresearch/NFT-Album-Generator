# NFT Generator UI

A simple web-based user interface for generating NFTs.

## Files

- `index.html`: The main HTML file for the UI.
- `generator_ui.css`: Stylesheet for the UI.
- `generator_ui.js`: JavaScript for the UI functionality.
- `Logo.png`: Project logo.

## Setup and Usage

To use the NFT Generator UI:

1.  Open the `index.html` file in your web browser.
2.  Drag your album art files into the designated area in the `index.html` page.
3.  Click the button to download the generated zip file.
4.  Upload the downloaded zip file to platforms like objkt or teia.

**Important Note on File Order:** The files (song and album art) will be uploaded in the order they are listed. Ensure they are in the desired order before generating the zip.
